# opentone

Work in progress.

This is a mp3 player in the style of an ipod classic. 

### Hardware
 - MCU: ESP32
 - Display: 2.2" LCD
 - SD Card: MicroSD
 - Audio: VS1063
 - Click wheel: MPR121
