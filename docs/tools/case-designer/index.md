# Case designer

Design the player's enclosure around the real parts: an aluminium case cut from standard stock with milled cutouts, the click-wheel exoskeleton and centre button, and a 3D-printed fill that holds everything in place. Import the KiCad board and the modules as STEP, STL, GLB or 3MF, place them, watch the clash and machinability checks, then export STEP for the mill and 3MF or STL for the printer. Everything runs in the browser; every size is in millimetres.
